지금 듣는 곡, 2~8명 방에서

답 주신 대로 풀 98 스킨입니다. 창 크롬·베벨·작업표시줄·비트맵 느낌의 목록을 정통 98 팔레트(티일 바탕, 그레이 창, 네이비 타이틀바)로 쓰고, Organic의 테라코타·세이지는 앨범아트와 상태 강조에만 남겼습니다.

  • 셋로그는 "번호 + 시간이 붙은 트랙 로그가 위에서 아래로 쌓이는" 구조로 해석했습니다. 특정 앱 이름이라고 하셨는데 어떤 앱인지 알려주시면 그 레이아웃에 정확히 맞추겠습니다.
  • 플랫폼 7개 전부 연결 대상. 곡을 누르면 내 기본 플랫폼으로 딥링크로 넘어갑니다.
  • 방 안에 같이 듣기(동시 재생) 스위치와 플레이리스트로 저장을 넣었습니다.
  • 보내주신 베이퍼웨이브 감성은 앨범아트에 적용했습니다. 저는 이미지를 생성할 수 없으니, 점선 슬롯에 이미지를 끌어다 놓으면 그대로 들어갑니다(1c의 네 칸). 비어 있는 동안은 CSS 디더 + 스캔라인 핑크·시안 처리로 채웁니다.

아래 1a가 동작하는 프로토타입, 1b~1d는 방 피드 레이아웃·앨범아트 트리트먼트 변형입니다.
